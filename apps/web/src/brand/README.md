# Reelmino brand kit

Source: official *Reelmino Brand Design* package (16 September 2026).

- Tokens: `design-tokens.json`, `tokens.css`
- Marks: `/public/brand/*.svg` — official path-based lockup and R+play symbol. Keep the symbol on the **left** of the wordmark; do not mirror in RTL.
- Type: Manrope (Latin) and Heebo (Hebrew) via `@fontsource`, OFL texts in `licenses/`. Fallback is Arial.
- Lime (`#D9F279`) is an accent only — not small text on white
- Dark mode is **not** defined; do not invert the palette
