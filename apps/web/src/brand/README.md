# Reelmino brand kit (in-repo)

Source: *Reelmino — Brand and product design book* (September 2026).

The original delivery folder (`logo-primary.svg` path outlines, `assets/fonts`, `prototype.html`) was not in this repository. This kit reconstructs tokens and a geometric **R + play** symbol from the book. It is **not** a legal uniqueness claim for the mark.

- Tokens: `design-tokens.json`, `tokens.css`
- Marks: `/public/brand/*.svg` — keep the symbol on the **left** in RTL; do not mirror it
- Type: Manrope (Latin) and Heebo (Hebrew) via `@fontsource`, OFL, Arial fallback
- Lime (`#D9F279`) is an accent only — not small text on white
- Dark mode is **not** defined; do not invert the palette
