# מדריך חיבור חשבונות לכלי השיווק של Reelmino

הכלי רץ על שרת Reelmino, בכתובת https://growth.reelmino.com. הוא נשאר פעיל כשמחשב הפיתוח כבוי. כמה אנשים נכנסים אליו מכל מחשב, וכולם רואים את אותו תוכן, אותם חשבונות ואותו לוח.

הוא מפרסם רק לחשבון אמיתי, ורק למקום שהחשבון מנהל: ערוץ יוטיוב, עמוד פייסבוק, אינסטגרם מקצועי שמקושר לעמוד, פרופיל טיקטוק, פרופיל לינקדאין, או ערוץ טלגרם.

לכל רשת יש שני דברים נפרדים:

1. **החשבון.** שם הגולשים רואים את הסרטון. את זה פותחים באתר של הרשת, כמו כל משתמש.
2. **המפתח.** זוג קודים שאפליקציית המפתחים של הרשת נותנת. אותו מדביקים בשרת, בקובץ `infra/hetzner/.env`. בלי המפתח לכלי אין רשות לפרסם.

אחרי שני אלה לוחצים בכלי על **חיבור** ומאשרים את החשבון בדפדפן. המפתח לבד לא מפרסם כלום.

X, וואטסאפ, פינטרסט ו-Threads בלי מפתח ובלי חיבור. מהם רק מייצאים טקסט וקובץ, ומעלים ידנית.

## כניסה ואנשים

פותחים https://growth.reelmino.com.

הסיסמה הראשונה היא `GROWTH_OPERATOR_PASSWORD` מתוך `infra/hetzner/.env` בשרת. זו סיסמת הכלי, לא סיסמה של גוגל, פייסבוק או של לקוח ב-Reelmino. בכניסה הראשונה אפשר להשאיר את שדה השם ריק.

אחרי הכניסה הראשונה הסיסמה נשמרת במסד על השרת. שינוי השורה בקובץ לא מחליף מפעיל שכבר קיים.

אנשים נוספים נוספים בכרטיסייה **מפעילים**: שם, וסיסמה של 8 תווים לפחות. כל אדם נכנס אחר כך עם השם והסיסמה שלו. אי אפשר למחוק את המפעיל האחרון.

## איפה שמים מפתח, ואיך מפעילים מחדש

מתחברים לשרת ועורכים את `~/studio-agents/infra/hetzner/.env`.

אחרי כל שינוי בקובץ, מתוך `studio-agents`:

```bash
docker compose -f infra/hetzner/docker-compose.yml --env-file infra/hetzner/.env up -d growth
```

הכלי קורא את המפתחות רק בהפעלה. הנתונים, הסרטונים והסיסמאות נשמרים בנפח `growth_data` על השרת.

כתובת הכלי כבר מוגדרת ל-`https://growth.reelmino.com`. אין צורך במנהרה ובאין צורך לכתוב `127.0.0.1`.

## איך נראה חיבור שעבד

בכרטיסייה **חשבונות**:

1. ליד הרשת כתוב **מוגדר**, לא **חסר**.
2. לוחצים **חיבור**. נפתח האתר של הרשת. מאשרים עם החשבון שלך.
3. חוזרים לכלי. מופיע שם החשבון, ואחרי **רענון יעדים** מופיעה שורה עם שם הערוץ או העמוד.
4. העמודה **פעיל** מסומנת. **אוטומטי** נשאר כבוי עד שמחליטים אחרת.

פרסום ראשון, ידני:

1. **תוכן** ← **ייבוא ערכת פרומו**, או **פריט ידני** עם כותרת.
2. מעלים קובץ mp4 אם אין עדיין סרטון.
3. בוחרים יעד מהרשימה ולוחצים **פרסום עכשיו**.
4. בכרטיסייה **תוצאות** מופיעים סטטוס, קישור לפוסט, או השגיאה.

**אוטומטי** אומר: חריץ בלוח 90 הימים יתפרסם לבד כשמגיע הזמן. בלי הסימון, החריץ מחכה לכפתור **אישור ופרסום**.

## כתובות שצריך לרשום באפליקציית המפתחים

רושמים אותן בדיוק, כולל `https`, ובלי סלאש בסוף. אם כבר רשומות כתובות אחרות למוצר, מוסיפים את אלה לידן ולא מוחקים את הקיימות.

```text
https://growth.reelmino.com/oauth/youtube/callback
https://growth.reelmino.com/oauth/facebook/callback
https://growth.reelmino.com/oauth/instagram/callback
https://growth.reelmino.com/oauth/tiktok/callback
https://growth.reelmino.com/oauth/linkedin/callback
```

## YouTube

**החשבון:** נכנסים ל-https://studio.youtube.com עם גוגל ופותחים ערוץ, אם עוד אין.

**המפתח:**

1. נכנסים ל-https://console.cloud.google.com ופותחים פרויקט, למשל `reelmino-growth`.
2. **APIs & Services → Library**, מחפשים `YouTube Data API v3`, ולוחצים **Enable**.
3. **APIs & Services → OAuth consent screen**. בוחרים External, ממלאים שם אפליקציה ומייל, ומוסיפים את המשתמש שלך כ-Test user. בסטטוס Testing רק מיילים שברשימה יכולים לאשר.
4. **APIs & Services → Credentials → Create credentials → OAuth client ID**. סוג: **Web application**.
5. אם משתמשים באותו לקוח גוגל של התחברות לאתר, כתובת החזרה כבר רשומה: `https://reelmino.com/auth/google/callback`. לקוח יוטיוב נפרד צריך גם את `https://growth.reelmino.com/oauth/youtube/callback`.
6. מעתיקים את Client ID ואת Client secret אל `infra/hetzner/.env` בשרת:

```text
YOUTUBE_CLIENT_ID=המזהה
YOUTUBE_CLIENT_SECRET=הסוד
```

7. מפעילים מחדש את מיכל growth, נכנסים ל**חשבונות**, ולוחצים **חיבור** ליד youtube. מאשרים את חשבון הגוגל של הערוץ.

היעד שמופיע הוא הערוץ. שם עולים הסרטונים.

## פייסבוק ואינסטגרם

שתי הרשתות משתמשות באותו מפתח של מטא. בכלי לוחצים **חיבור** פעמיים: פעם לפייסבוק ופעם לאינסטגרם.

**החשבונות:**

1. עמוד פייסבוק שאתה מנהל, לא פרופיל פרטי ולא קבוצה.
2. אינסטגרם שהוא חשבון מקצועי (עסק או יוצר), ומקושר לאותו עמוד. הקישור נעשה בהגדרות האינסטגרם, תחת החשבון המקצועי והעמוד המקושר.

**המפתח:**

1. נכנסים ל-https://developers.facebook.com/apps ויוצרים אפליקציה מסוג Business.
2. מוסיפים את המוצר **Facebook Login for Business**, או Facebook Login.
3. ב-**Facebook Login → Settings**, בשדה **Valid OAuth Redirect URIs**, מדביקים שתי שורות:

```text
https://growth.reelmino.com/oauth/facebook/callback
https://growth.reelmino.com/oauth/instagram/callback
```

4. ב-**App settings → Basic** מעתיקים App ID ו-App secret אל `infra/hetzner/.env`:

```text
META_APP_ID=המזהה
META_APP_SECRET=הסוד
```

5. כל עוד האפליקציה במצב Development, רק מי שרשום כאדמין, מפתח או בודק של האפליקציה יכול לאשר אותה. מוסיפים את המשתמש שלך תחת **App roles**.
6. מפעילים מחדש את מיכל growth. **חיבור** ליד facebook, ואחר כך **חיבור** ליד instagram. בשניהם מאשרים את אותו חשבון פייסבוק, ונותנים גישה לעמוד.

יעדים שיופיעו: העמוד בפייסבוק, וחשבון האינסטגרם המקושר. קבוצה שרק הצטרפת אליה לא תופיע.

פייסבוק ואינסטגרם מורידים את קובץ הווידאו מהכתובת הציבורית של הכלי. הכתובת הזו כבר `https://growth.reelmino.com`, ולכן אין צורך במנהרה.

פרסום לאינסטגרם ולפייסבוק של אנשים מחוץ לתפקידי האפליקציה דורש אישור של מטא לאפליקציה. לחשבון שלך, בזמן שהאפליקציה בפיתוח ואתה רשום בה, אפשר לבדוק בלי האישור הזה.

## TikTok

**החשבון:** פרופיל טיקטוק רגיל שלך.

**המפתח:** בשרת כבר מולאים `TIKTOK_CLIENT_KEY` ו-`TIKTOK_CLIENT_SECRET`. אם פותחים אפליקציה חדשה, מעדכנים את שתי השורות האלה ב-`infra/hetzner/.env` ומפעילים מחדש.

1. נכנסים ל-https://developers.tiktok.com לאפליקציה הקיימת, או יוצרים אחת.
2. מוסיפים את **Login Kit** ואת **Content Posting API**.
3. ב-Redirect URI מדביקים `https://growth.reelmino.com/oauth/tiktok/callback`. לא מוחקים כתובת שכבר רשומה שם.
4. אם המפתח חדש, מעתיקים:

```text
TIKTOK_CLIENT_KEY=המזהה
TIKTOK_CLIENT_SECRET=הסוד
```

5. לוחצים **חיבור** ליד tiktok.

`TIKTOK_DIRECT_POST` בשרת הוא `0`. עד שטיקטוק מאשרים את האפליקציה לפרסום ישיר, הסרטון נכנס לתיבת הטיוטות של החשבון. מסיימים את הפרסום באפליקציית טיקטוק. אחרי האישור שלהם משנים את השורה ומפעילים מחדש:

```text
TIKTOK_DIRECT_POST=1
```

ואז מחברים את החשבון שוב, כדי שההרשאה תכלול פרסום ישיר.

## לינקדאין

**החשבון:** הפרופיל האישי שלך. זה היעד שאליו הכלי מפרסם עם ההגדרה הרגילה.

**המפתח:** עדיין אין מפתח לינקדאין בשרת.

1. נכנסים ל-https://www.linkedin.com/developers/apps ויוצרים אפליקציה.
2. מבקשים את המוצר שמאפשר לשתף בפיד האישי (Share on LinkedIn). בלי האישור הזה החיבור ייכשל.
3. ב-Auth, תחת Redirect URLs, מדביקים `https://growth.reelmino.com/oauth/linkedin/callback`.
4. מעתיקים אל `infra/hetzner/.env`:

```text
LINKEDIN_CLIENT_ID=המזהה
LINKEDIN_CLIENT_SECRET=הסוד
LINKEDIN_SCOPES=openid profile w_member_social
```

5. מפעילים מחדש את מיכל growth, ולוחצים **חיבור** ליד linkedin.

## טלגרם

אין אפליקציית מפתחים ואין שורות בקובץ `.env`.

1. בטלגרם פותחים שיחה עם `@BotFather`, שולחים `/newbot`, ובוחרים שם. מעתיקים את הטוקן שהוא מחזיר.
2. יוצרים ערוץ, או משתמשים בערוץ קיים, ומוסיפים את הבוט כמנהל עם הרשאת פרסום הודעות.
3. בכלי, ב**חשבונות**, מדביקים את הטוקן בשדה **טוקן בוט טלגרם**.
4. בשדה **מזהה צ'אט או @ערוץ** כותבים את שם הערוץ עם שטרודל, למשל `@reelmino`, או את המספר של הערוץ.
5. לוחצים **חיבור טלגרם**.

אם הערוץ לא הופיע, לוחצים **רענון יעדים** אחרי שהבוט כבר מנהל.

## מה מעלים ידנית

בפריט תוכן יש כפתורי **ייצוא** עבור x, whatsapp, pinterest ו-threads. הכפתור מציג את הטקסט וקישור לקובץ. מעלים אותם בעצמך באותה רשת. אין שם מפתח ואין כפתור חיבור.

## הפצה לקבוצות

בכרטיסייה **קבוצות** רושמים קבוצות שאתם כבר חברים בהן ויש לכם בהן הרשאת כתיבה. כל פריט שמתפרסם יוצר משימה אחת לכל קבוצה פעילה. אותו פריט לא נשלח לאותה קבוצה פעמיים, ויש מרווח מינימלי בימים בין פרסומים בכל קבוצה (ברירת המחדל 7).

| רשת | איך זה יוצא | מה מדביקים |
|---|---|---|
| טלגרם | אוטומטי דרך הבוט המחובר | `@שם-הקבוצה` או המזהה המספרי |
| דיסקורד | אוטומטי דרך Webhook | `https://discord.com/api/webhooks/...` |
| פייסבוק | העתקה ופתיחת הקבוצה | `https://www.facebook.com/groups/...` |
| לינקדאין | העתקה ופתיחת הקבוצה | `https://www.linkedin.com/groups/...` |
| וואטסאפ | העתקה ופתיחה באפליקציה | `https://chat.whatsapp.com/...` |
| Reddit | טופס פרסום ממולא | `https://www.reddit.com/r/...` |
| X קהילות | העתקה ופתיחת הקהילה | `https://x.com/i/communities/...` |

פייסבוק, לינקדאין, וואטסאפ, Reddit ו-X לא מאפשרים לתוכנה לפרסם בקבוצה, ולחיצה אוטומטית בחשבון האישי מסכנת אותו. לכן שם הכלי מכין את הטקסט, מעתיק ופותח, ואתם מדביקים ולוחצים **פורסם** בכלי.

- **טלגרם:** מוסיפים את הבוט המחובר לקבוצה (בערוץ: כמנהל עם הרשאת פרסום). הכלי בודק שהבוט יכול לכתוב לפני ההוספה.
- **דיסקורד:** הגדרות הערוץ ← Integrations ← Webhooks ← New Webhook ← Copy Webhook URL. הכתובת נשמרת מוצפנת.
- **טייס אוטומטי** (טלגרם ודיסקורד): שולח לבד, פריט אחד לכל קבוצה, ורק אחרי שעבר המרווח.
- הקישור בטקסט מסומן `utm_medium=community`, ושם הקבוצה ב-`utm_term`, כדי לראות ב-Analytics מה הביאה כל קבוצה.

### הכנה לפני ההפצה

**1. רשימת הקבוצות.** לכל קבוצה שאתם חברים בה ומותר בה לפרסם, שומרים את הכתובת:

| רשת | מה לשמור |
|---|---|
| פייסבוק | `facebook.com/groups/...` |
| לינקדאין | `linkedin.com/groups/...` |
| וואטסאפ | קישור הזמנה `chat.whatsapp.com/...` מפרטי הקבוצה, או ממנהל הקבוצה |
| Reddit | `reddit.com/r/...` |
| X קהילות | `x.com/i/communities/...` |

ליד כל קבוצה רושמים את הכללים שלה: האם מותר קידום עצמי, ובאילו ימים. הכללים נכנסים לשדה **כללי הקבוצה**, והמרווח בימים נקבע לפיהם.

**2. טלגרם.**
1. אם אין עדיין בוט: ב-@BotFather שולחים `/newbot` ומעתיקים את הטוקן. ב**חשבונות** מדביקים אותו ולוחצים **חיבור טלגרם**.
2. מוסיפים את הבוט לכל קבוצה. בערוץ הבוט צריך להיות מנהל עם הרשאת פרסום.
3. ב**קבוצות** בוחרים טלגרם וכותבים `@שם-הקבוצה`. בקבוצה פרטית בלי @שם: כותבים בה הודעה, לוחצים **רענון יעדים** ובוחרים אותה מהרשימה.

**3. דיסקורד**, אם יש לכם שרת: בכל ערוץ נכנסים להגדרות הערוץ, Integrations, Webhooks, New Webhook, ואז Copy Webhook URL. צריך הרשאת ניהול Webhooks באותו שרת.

**4. מפתחות שעדיין חסרים בשרת:** YouTube, Meta ולינקדאין. בלי מפתח Meta אין פרסום לעמוד הפייסבוק, ולכן קבוצות פייסבוק לא יקבלו משימות "אחרי פרסום בעמוד". עד אז משנים בקבוצה את **מתי ליצור משימה** ל**כל פרסום של הפריט**, או משתמשים בכפתור **משימות לכל הקבוצות**.

**Reddit:** כדאי חשבון עם היסטוריה של השתתפות אמיתית. הרבה קהילות מוחקות פוסטים קידומיים מחשבון חדש, וחלקן אוסרות קידום עצמי לגמרי. גם בפייסבוק ובלינקדאין: מרווח של שבוע לפחות, וטקסט שמתאים לקהל של הקבוצה.

**5. בדיקה ראשונה.**
1. מוסיפים קבוצת טלגרם אחת וקבוצת פייסבוק אחת.
2. בעורך התוכן לוחצים **משימות לכל הקבוצות** על פריט אחד.
3. בטלגרם לוחצים **שליחה עכשיו**. בפייסבוק לוחצים **העתקה ופתיחת הקבוצה**, מפרסמים, וחוזרים ללחוץ **פורסם**.
4. רק אחרי שזה עובד מסמנים **טייס אוטומטי**.

## אחרי שהחשבון מחובר

| פעולה בכלי | מה קורה |
|---|---|
| ייבוא ערכת פרומו | 18 סרטוני ההסבר של Reelmino, עם טקסט לכל רשת |
| ייבוא לוח 90 יום | לוח פרסום. בלי אוטומטי הוא רק ממתין לאישור |
| פרסום עכשיו | שולח את הפריט ליעד שבחרת |
| תזמון מאושר | שולח בזמן שבחרת, גם אם אוטומטי כבוי |
| אוטומטי על יעד | חריצי הלוח של אותה רשת יוצאים לבד |
| מפעילים | מוסיף אדם עם שם וסיסמה לאותו כלי |
