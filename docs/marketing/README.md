# Prompt2Spot global launch kit

This folder converts the 90-day advertising plan into operating assets:

1. [Positioning and creative](./01-positioning-and-creative.md) — SMB/Agency messages, landing copy, objections, 30 hooks and proof requirements.
2. [90-day content calendar](./02-90-day-content-calendar.md) — weekly production system, 13-week publishing calendar and reusable scripts.
3. [Paid media playbook](./03-paid-media-playbook.md) — ₪2K–₪4K allocation, Meta/Search structures, ad copy and stop rules.
4. [Agency and affiliate outreach](./04-agency-and-affiliate-outreach.md) — targeting, four-touch sequence, paid pilot and partner terms.
5. [Measurement](./05-measurement-and-experimentation.md) — UTMs, event contract, dashboards, KPI definitions and decision gates.

## Launch order

### Before traffic

- Produce the main demo and five industry examples.
- Create separate SMB and Agency landing pages using the approved copy.
- Publish pricing, technical-failure and creative-revision rules that match billing behavior.
- Implement consent, attribution and the event contract.
- Verify backend purchase and video-completion events.

### Days 1–10

- Publish organic assets from weeks 1–2.
- Begin personalized agency and creator outreach.
- Score each asset after 48–72 hours.
- Do not activate broad paid acquisition.

### Days 11–30

- Boost only qualifying organic assets.
- Launch tightly grouped English-market tests.
- Review search terms twice weekly.
- Hold the first formal decision-gate review after enough data exists.

## Owners

Assign one person to each role even if a founder holds multiple roles:

- Creative production
- Distribution/community
- Paid acquisition
- Agency/partner sales
- Analytics and economics

Every Friday, each owner supplies the metrics and decisions required by the relevant playbook. The meeting ends with an explicit stop, repair, continue or scale decision for every active experiment.
